# Prompt Chaining

## Objective

Prompt chaining breaks a complex task into smaller sequential prompts.

---

## Example Workflow

### Prompt 1

```
Summarize this research paper.
```

↓

### Prompt 2

```
Identify the key findings from the summary.
```

↓

### Prompt 3

```
Create an executive summary for business leaders.
```

---

## Advantages

- Better organization
- Easier validation
- Reduced hallucinations
- Higher consistency

---

## Evaluation

Prompt chaining is especially useful for research, document analysis, and report generation workflows.
