## About

Hello! I'm Hemant Patil.

This repository showcases my practical work in AI evaluation and LLM quality improvement. It contains real-world examples of prompt engineering, factuality verification, evaluation rubrics, reasoning benchmarks, training data design, and QA case studies inspired by modern AI evaluation workflows.

My goal is to build reliable, transparent, and scalable evaluation systems that help improve the quality of frontier AI models.
